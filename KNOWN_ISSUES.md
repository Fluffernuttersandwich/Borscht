# Borscht --- Known Issues

This page tracks known issues in the current version of **Borscht** and
any available workarounds.

------------------------------------------------------------------------

## 1. Skip Prologue --- Game Launches Muted

### Issue

When using the **Skip Prologue** mod, the game may launch with no sound.

### Workaround

When you first spawn in front of the **Bubble anomalies**, where you
first meet **Richter**:

1.  Wait until you have full control of your character.
2.  Tap the **Escape** key **three times**.

This will open and close the game menu and restore the game audio.

------------------------------------------------------------------------

## 2. OXA - Prototype --- Weapon Visual Issues

### Issue

Some of the new or reskinned weapons added by **OXA - Prototype** are
not displaying correctly.

Affected weapons may appear with:

-   Exposed internal components
-   Floating bullets
-   Floating weapon attachments/mods
-   Other incorrect or incomplete weapon visuals

### Workaround

There is currently **no workaround**.

We are waiting for an **OXA - Prototype** update to resolve the affected
weapon visuals.

------------------------------------------------------------------------

## 3. Immersive HUD --- HUD Missing When Starting a New Game

### Required Setting

Before playing, make sure the following in-game setting is configured:

**Settings → UI → Ammo Counter → Always ON**

> **Always ON is mandatory.** The game's default setting is **Auto**.

### Issue

When first loading into a **new game**, HUD elements may not display.

### Workaround

1.  Save your game.
2.  Exit to the main menu.
3.  Reload your save.

The HUD elements should display correctly after reloading.
