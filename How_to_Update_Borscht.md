# 🔄 HOW TO UPDATE THE BORSCHT MOD LIST

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## ⚠️ IMPORTANT --- READ BEFORE UPDATING

There is **NO GUARANTEE** that you can update Borscht and safely
continue an existing save.

If you are happy with your current playthrough, **stay on your current
revision until you are ready to start a new game.**

Major changes to: 
- Stalker 2 itself
- The Cost of Hope DLC
- Mod frameworks
- Gameplay overhauls
- Script changes

can potentially affect existing saves.

If there are no critical fixes or changes you absolutely need, **DON'T
UPDATE!**

## 😄 DON'T FOMO!

Borscht isn't going anywhere.

A newer revision will always be available when you are ready for your
next adventure.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 🛑 BEFORE YOU UPDATE

Strongly consider:

• Finishing your current playthrough on your current Borscht revision.\
• Starting a **new save** after major Borscht updates or major Stalker 2
patches.\
• Reading the latest update notes before deciding if you actually need
to update.\
• Backing up your current save files if you want the option to return.\
• Remembering that large mod list updates can introduce changes that an
existing save was never designed to handle.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 📢 UPDATE NOTIFICATIONS

Check **#borscht-updates** for new Borscht revisions and important
update information.

Want to be notified when a new Borscht revision is released?

Use:

`$borscht`

This opts you into Borscht update notifications.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 🔧 HOW TO UPDATE

You update Borscht through **Wabbajack**, basically the same way you
installed it the first time.

1.  Close **Mod Organizer 2 (MO2)** completely.
2.  Open **Wabbajack**.
3.  Download/select the newest **Borscht Mod List**.
4.  Select the **same installation location** as your existing Borscht
    installation.
5.  Allow Wabbajack to **Overwrite** the existing installation.
6.  Wait for Wabbajack to complete before opening MO2 again.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 💡 WABBAJACK DOES NOT REDOWNLOAD EVERYTHING

Wabbajack reuses files you already have whenever possible.

During an update, it normally only downloads:

-   New mods
-   Updated mods
-   Changed files
-   Missing files

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## ⚠️ YOU MAY NEED A NEW SAVE

Depending on what changed between Borscht revisions, continuing an
existing save may cause problems.

Examples:

-   Major gameplay changes
-   New quest/content mods
-   Framework updates
-   Stalker 2 patches
-   DLC compatibility changes

When in doubt:

**Major Borscht Revision = Consider Starting Fresh**

You are never required to update simply because a newer revision exists.
