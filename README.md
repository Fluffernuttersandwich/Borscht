## Vision

To provide players with a **deluxe, highly customizable Vanilla+ overhaul** of S.T.A.L.K.E.R. 2: Heart of Chornobyl while preserving the identity, atmosphere, and spirit of the original game.

### Target Audience

Anyone who enjoys S.T.A.L.K.E.R. 2 and wants **more of it**.

More immersion.  
More quality of life.  
More variety.  
More atmosphere.  
More ways to customize the Zone.

Without requiring you to spend days assembling and maintaining everything yourself.

### Core Strength

**Modularity.**

Borscht isn't intended to tell you exactly how S.T.A.L.K.E.R. 2 must be played.

It provides a curated collection of compatible mods, an organized Mod Organizer 2 installation, and a tested default configuration.

From there, you decide what kind of Zone you want.

**Borscht provides the ingredients. You decide what goes in the bowl.**

## What is Borscht?

Borscht is a curated **Wabbajack Mod List** for S.T.A.L.K.E.R. 2: Heart of Chornobyl.

The list brings together gameplay improvements, visual enhancements, quality-of-life changes, equipment, immersion mods, fixes, rebalances, and larger overhauls into a single organized installation.

Rather than manually downloading, extracting, restructuring, installing, and maintaining a large collection of S.T.A.L.K.E.R. 2 mods, Wabbajack and Mod Organizer 2 handle much of the tedious work for you.

The goal is simple:

> **Spend less time wrestling with mod installation and more time in the Zone.**

Borscht provides a recommended default configuration intended to work as a cohesive Vanilla+ experience.

However, that configuration is only the starting point.

Many included mods can be individually enabled or disabled through Mod Organizer 2, allowing experienced users to customize Borscht considerably.

## Distinctive Features

### 🥣 Highly Modular

Borscht is designed around player choice.

Many included mods can be individually enabled or disabled through Mod Organizer 2.

Want something close to Vanilla+?

You can do that.

Want more aggressive gameplay changes?

You can do that too.

Want prettier weather, better equipment, quality-of-life improvements, and very little gameplay rebalance?

Build that bowl.


### ☢️ Curated for the Zone

Mods aren't included simply because they exist.

Potential additions are considered based on factors such as:

- Compatibility
- Stability
- Usefulness
- Performance
- Quality
- Ease of installation and maintenance
- Interaction with other included mods
- Whether the mod meaningfully improves the experience


### 🧰 Organized Through Mod Organizer 2

Mods are separated and organized rather than simply dumped into the game's installation directory.

This makes it significantly easier to:

- Enable or disable optional mods
- Troubleshoot problems
- Maintain the list
- Update individual components
- Experiment with different configurations
- Keep track of what is actually installed


### 📝 Helpful MO2 Notes

Where appropriate, mods include concise notes explaining:

- What the mod does
- Important requirements
- Known incompatibilities
- Recommended settings
- Optional variants
- Other information worth knowing before enabling it


### 🧪 Tested Default Configuration

Borscht includes a default profile representing the configuration the list is primarily developed and tested against.

Casual users can simply use the provided configuration.

Advanced users are encouraged to create their own MO2 profile before experimenting.

## Mod Organizer 2

Borscht uses **Mod Organizer 2 (MO2)** to manage the list.

If you've never used MO2 before, don't panic.

You do **not** need to become an expert to use Borscht.

The supplied configuration is intended to provide a ready-to-play experience.

MO2 also provides experienced users with significantly more control over their installation.


### Virtual File System

Whenever possible, Borscht keeps modded files inside the Mod Organizer 2 environment rather than permanently modifying the original game installation.

This helps keep the base game cleaner and makes troubleshooting, updating, and removing mods considerably easier.


### Profiles

MO2 profiles allow different configurations of the same installed mod list.

For example:

- **Default** — The official Borscht configuration
- **Personal** — Your customized version
- **Testing** — Somewhere to experiment without disturbing your normal setup

Before making extensive changes, create a copy of the default profile.

## Installation

> 🚧 **Borscht is currently under development.**

Complete installation instructions will be added before the first public release.

The eventual installation process will generally consist of:

1. Prepare a clean and supported S.T.A.L.K.E.R. 2 installation.
2. Download Borscht through Wabbajack.

## Customizing Borscht

Customization is one of the primary goals of the list.

However, there is an important distinction between:

> **Borscht**

and

> **Your Borscht**

The supplied default profile is the configuration primarily tested and supported by the project.

Once you've confirmed that Borscht works correctly, create a new MO2 profile before making substantial changes.

Then experiment.

Enable something.

Disable something.

Make the Zone prettier.

Make it uglier.

Make it easier.

Make it harder.

Make it stranger.

Make it yours.


### ⚠️ A Note About Compatibility

S.T.A.L.K.E.R. 2 mod conflicts are not always obvious.

Two mods can alter the same underlying game assets without producing the sort of clear conflict information users may expect from heavily established modding ecosystems.

Because of this, **not every possible combination of optional mods can be guaranteed compatible.**

Known requirements and incompatibilities will be documented whenever possible.

## Updating Borscht

Borscht will receive revisions as:

- Included mods are updated
- New mods are added
- Mods become obsolete
- Compatibility problems are discovered
- S.T.A.L.K.E.R. 2 itself is updated
- Better alternatives become available

Always read the release notes before updating.

Some revisions may be simple updates.

Others may require additional instructions due to changes in S.T.A.L.K.E.R. 2 or individual mods.

**Do not blindly update individual mods inside Borscht unless you understand what the update changes.**

The newest version of a mod is not automatically the version currently supported by the list.

## Troubleshooting

If you encounter a problem:

1. Confirm your S.T.A.L.K.E.R. 2 version matches the currently supported Borscht version.
2. Confirm you're using the supplied default profile.
3. Disable any mods you personally added.
4. Undo manual changes made outside MO2.
5. Reproduce the problem.
6. Gather any relevant logs or screenshots.
7. Check the Known Issues documentation.
8. Ask for help if the problem remains.

More detailed troubleshooting information will be maintained here:
